### 3. 同款卖家 = 竞对核弹（企业主体 + 价格战）

`/modal/otherOffersFromSellers?product_id=<sku>&sort=price` → `webSellerList.sellers[]`：

- **一个 SKU 有 112 个卖家在卖**（实测）
- 每个卖家带：**企业凭据**（公司名/注册地址/国家/营业模式）+ 价格 + 配送承诺
- 实测全部是中国跨境公司：漳州（Zhaotuo）、厦门（Huimeifeng）、晋江（Fuyida）、阜阳（Liangaqi）、珠海（haoou）……
- `sort=price` 直接给价格战排序：193₽ → 201₽ → 204₽ → 212₽ → 215₽

→ 判断：**这个品是不是红海**（卖家数）、**最低价能不能打**（价格带）、**货源地**（供应链格局）。

## 三、选品工作流（建议）

```
1. 需求探测：autocomplete 种子词 → 联想词 + 关联类目 + 品牌（找增长方向）
2. 市场体检：类目页 filtersDesktop（垄断度/价格带/中货比/履约）+ 列表页价格分布
3. 竞对扫描：头部 SKU → otherOffersFromSellers（卖家数 + 企业凭据 + 价格带）
4. 实力评估：主要卖家店铺页（订单量/上新/品类广度）
5. 机会判断：
   - 卖家数 < 20 且价格带分散 → 蓝海
   - 卖家数 > 50 且价格带集中 → 红海（需差异化）
   - 全部中国货源 → 供应链竞争，拼履约/设计
```

## 四、类目 → 关键词（实测结论 + 修正）

> **修正**：PDP2 的 `webHashtags` 是**买家 UGC 标签**（全部 # 开头，每品 16~30 个），**不是 Ozon 官方关键词体系**，不能直接当"类目关键词库"（此前结论撤回）。

### SKU 可用的"关键词"数据（按官方程度排序）

| 来源 | 位置 | 形态 | 实例（SKU 5081332378） |
|---|---|---|---|
| **标题（官方）** | `webProductHeading.title` | 品牌+品类+属性+场景词 | Сенсорная развивающая доска антистресс игрушка-пазл для детей |
| **特性（官方）** | `webShortCharacteristics.characteristics[]` | 属性名值对（Тип/Материал…） | Тип: Игрушка-антистресс |
| **关联类目（SEO）** | PDP2 `tagList.items[]`（10 条，非 #） | 类目名互链 | Fidget Spinner / Жмялка пищалка |
| **买家标签（UGC）** | PDP2 `webHashtags.badges[]`（16~30 条，# 开头） | UGC 标签，点击跳搜索 | #антистресс / #кликер / #спиннер |

### 结论

- **SKU 没有独立的官方 keywords 字段**（PDP 81 个 widget + 页面 HTML 均无 meta keywords / JSON-LD keywords）
- 最接近"SKU 关键词"的是**标题 + 特性值**（卖家填写、平台结构化）
- `#` 标签是买家打的（0~30 个/品），可作需求信号参考，不能代表类目关键词
- 类目级关键词仍需：类目页 title/h1 + SKU 标题分词聚合 + autocomplete 联想

## 五、附带发现（采集效率）## 五、附带发现（采集效率）

1. **列表页不查 PDP 即得价格/评分/评价数/促销/配送**——批量选品扫描成本极低
2. 翻页需带 `paginator_token` + `search_page_state`（服务端状态），不是简单 page=N
3. `Магазин` 筛选（key=seller）直接给类目头部店铺列表 + sellerId
4. 同款卖家 modal 的 `sort=price|date` 控制竞对排序
